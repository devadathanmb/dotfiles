## Quick setup:

> [!NOTE]
> These dotfiles are configured to work on my system, these may or may not work the same out of the box on your system. So make needed the changes. Checkout **bootstrap.sh** script for the required tools and packages.

<br>

1. Clone the repo:

```bash
git clone https://github.com/devadathanmb/dotfiles.git
```

2. Setup the symlinks:

```bash
cd dotfiles/
./install
```
